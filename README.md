Confronta i fondi pensione italiani usando dati ufficiali COVIP.

Funzionalità principali:
- guida l'utente al download dei dati ufficiali COVIP, e al caricamento degli stessi per il calcolo 📥
- calcola un punteggio combinando ISC stimato e rendimento stimato sul periodo scelto 📊
- consente di filtrare e ordinare la classifica dei fondi pensione 🔎

Questa applicazione è pensata per analisi informative e non sostituisce le informazioni ufficiali COVIP.
